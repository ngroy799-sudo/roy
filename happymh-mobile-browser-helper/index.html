happymh mobile helper

用你本機瀏覽器、手機模式直接開原站；廣告靠 uBlock Origin 攔截。本頁唔抓取、唔代理網站內容。

開原站 安裝 uBlock Origin

一、攔截廣告

  1. 安裝 uBlock Origin（Chrome / Edge 擴充功能）。
  2. 開原站後，右上角盾牌圖示確認已啟用。
  3. 仍有彈窗時，撳盾牌 → 暫時加強攔截／重新整理。

二、手機模式（最穩）

  1. 喺原站頁面按 F12。
  2. 按 Ctrl+Shift+M（Mac：Cmd+Shift+M）開裝置工具列。
  3. 頂部選 iPhone，或闊度設約 390。
  4. 重新整理頁面。

開發者工具手機模式比單改 User-Agent 更準，排版通常會正常。

三、一鍵啟動腳本（推薦）

  • Windows：雙擊 launch-chrome.bat 或 launch-edge.bat
  • macOS / Linux：執行 ./launch-chrome.sh
  • 改預設網址：複製 config.env.example 做 config.env，改 TARGET_URL
