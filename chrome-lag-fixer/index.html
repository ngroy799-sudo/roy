chrome-lag-fixer

點解個 Chrome 成日 LAG 機

多數唔係 Chrome「壞咗」，而係合成畫面跟錯咗塊芒、同 NVIDIA 硬件加速打架、 再加擷取卡／OBS／廣告分頁。下面按你呢部機（雙芒、擷取卡、NVIDIA）排優先次序。

短答： 先對證兩件事——雙螢幕唔同 Hertz，同 Chrome 硬件加速。 超過一半 Windows + NVIDIA + 雙芒組合，關硬件加速或者統一刷新率就會即刻順。

最可能原因（按你部機排）

1. 雙螢幕唔同 Hertz

最常見

遊戲芒 144／165／240Hz，電腦芒 60Hz。Chrome 嘅 compositor 會跟錯一邊嘅 VSync， 結果捲動、拖視窗、YouTube、漫畫頁都會一卡一卡。你有遊戲芒 + 電腦芒，呢個優先查。

對證：暫時將兩塊芒設成同一個刷新率，或者只喺高 Hertz 嗰塊開 Chrome。

2. NVIDIA + Chrome 硬件加速

最常見

Chrome 預設用 GPU 畫網頁。RTX 40／50 + 新 driver，再疊 Skia Graphite／Vulkan， 好常出現「CPU 唔高但畫面頓」。關硬件加速如果即刻順，就係呢條。

對證：完全退出 Chrome，跑 02-test-no-gpu.bat。

3. 擷取卡被當成多一塊芒

中

AVerMedia GC553 Pro 有時會令 Windows／Chrome 以為多咗一個 display， 刷新率同 GPU 排程被打亂。畫面仲喺，但瀏覽器開始 stutter。

對證：拔擷取卡 HDMI／USB 再開 Chrome。顯示設定唔好將桌面延伸去張卡。

4. OBS／NVIDIA Overlay 搶 GPU

中

背景編碼 + Chrome GPU 加速一齊排隊。GeForce Overlay、Instant Replay、Streaming Center 開住都同樣。

對證：工作管理員結束 OBS、NVIDIA Share、AVerMedia 相關程式，再開 Chrome。

5. 廣告站、分頁、Profile 脹

中

漫畫站彈窗／自動播放片、幾十個分頁、擴充功能、GPUCache 幾百 MB 以上， renderer 會拖死。Shift+Esc 開 Chrome 工作管理員睇邊個分頁食 CPU。

對證：跑 01-diagnose.bat 睇 RAM 同 cache；廣告站裝 uBlock Origin。

三分鐘對證（照次序）

  1. 雙擊 01-diagnose.bat，留低 reports/chrome-lag-report.txt。
  2. 完全退出 Chrome → 02-test-no-gpu.bat → 用會 lag 嘅網站試 30 秒。
  3. 順咗：去 chrome://settings/system 關閉「使用圖形加速功能」，或者改用 04-launch-smooth.bat。
  4. 仍然 lag：顯示設定將兩塊芒改同一個 Hertz；退出 OBS／Overlay；拔擷取卡再試。
  5. Cache 好大就跑 03-clean-gpu-cache.bat（唔刪書籤／密碼）。

本機工具

01-diagnose.bat

GPU、芒 Hertz、Chrome RAM、擷取卡、OBS。

02-test-no-gpu.bat

關 GPU 加速重開。最緊要嘅 A/B。

03-clean-gpu-cache.bat

清 GPUCache／ShaderCache／Code Cache。

04-launch-smooth.bat

保留加速，但強制 D3D11、關 Graphite／Vulkan。

喺網址列貼呢啲（要喺 Chrome 入面開）：

鍵盤 Shift + Esc = Chrome 工作管理員。如果 GPU 進程不停閃紅／重啟，就係驅動衝突。

NVIDIA、G-SYNC、擷取卡

  • NVIDIA 控制台 → 管理 3D 設定 → 程式：chrome.exe → 電源管理「偏好最高效能」；垂直同步用「應用程式控制」。
  • 有 G-SYNC：改「只限全螢幕」。視窗模式 Chrome + G-SYNC 好易 stutter。
  • Windows 設定 → 系統 → 顯示器 → 圖形 → 變更預設圖形設定：試關閉「硬件加速 GPU 排程」（HAGS）。
  • 同一頁將 Chrome 指定「高效能」NVIDIA，唔好用自動。
  • GC553 Pro：唔好把桌面延伸去擷取卡；唔錄就拔 HDMI 對證。
  • 漫畫站：裝 uBlock Origin，廣告 iframe 本身就可以令 Chrome 卡死。
本工具只讀本機資料同用官方 Chrome 參數重開瀏覽器，唔改系統驅動、唔抓網站內容。 報告可以連 reports/chrome-lag-report.txt 一齊交返嚟繼續睇。
